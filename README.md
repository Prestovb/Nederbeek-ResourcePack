# Nederbeek ResourcePack

De officiele Nederbeek-iconenset voor de Marketplace- en Guilds/claimchest-menu's.
Deze pack verandert niet de volledige Minecraft-inventory-GUI.

## Serverinstallatie

Gebruik altijd de downloadlink, SHA-1 en pack-ID uit de nieuwste GitHub Release
in `server.properties`.

De zip moet direct `assets/`, `pack.mcmeta` en `pack.png` bevatten.
