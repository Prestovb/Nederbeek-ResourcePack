# Nederbeek ResourcePack

De officiele Nederbeek-iconenset voor de Marketplace- en Guilds/claimchest-menu's.
Deze pack verandert niet de volledige Minecraft-inventory-GUI.

## Serverinstallatie

Gebruik voor versie 1.0.0 deze waarden in `server.properties`:

```properties
resource-pack=https\://github.com/Prestovb/Nederbeek-ResourcePack/releases/download/v1.0.0/Nederbeek-ResourcePack-1.0.0.zip
resource-pack-sha1=549f0731d833f51823597b10c9ca98f163e51258
resource-pack-id=128b9f34-e12a-4580-8a77-3762b0b39c8c
require-resource-pack=true
```

De zip moet direct `assets/`, `pack.mcmeta` en `pack.png` bevatten.
